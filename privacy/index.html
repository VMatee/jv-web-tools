Privacy Policy for JV-web-tools

Last updated: September 19, 2026

JV-web-tools is a browser extension designed as a developer utility for exporting website data from the currently active browser tab into a structured web-compatible JSON file.

Data accessed by the extension

When the user explicitly starts an export, JV-web-tools may access:

  • Cookies associated with the current website.
  • localStorage data associated with the current website.

Cookies may contain authentication or session information. localStorage may contain website content, application state, preferences, identifiers, or other information created by the website.

How data is used

The accessed data is used only to create the JSON export requested by the user for website development, debugging, testing, migration, or automation workflows.

Local processing

JV-web-tools processes exported website data locally on the user's device. The extension does not upload exported cookies, localStorage data, or generated JSON files to the developer or to an external JV-web-tools server.

Data sharing and sale

JV-web-tools does not sell user data. JV-web-tools does not transfer user data to third parties for advertising, creditworthiness, lending, or purposes unrelated to the extension's single purpose.

Website access

Website access is requested only when needed for the website from which the user chooses to export data.

Data retention

JV-web-tools does not maintain a remote database of exported website data. Exported JSON files remain under the user's control on their device.

Security

Exported files can contain sensitive authentication information. Users should treat exported JSON files as sensitive data and should not publish or share them publicly.

Changes to this policy

This policy may be updated when JV-web-tools functionality or data-handling practices change. Updates will be published on this page with an updated date.

Contact

For questions, bug reports, or privacy concerns, use the project's GitHub Issues page.
