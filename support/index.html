JV-web-tools Support

Help, bug reports, and privacy questions.

JV-web-tools is a developer utility for exporting cookies and localStorage from the currently active website into structured web-compatible JSON.

Bug reports and support

Use GitHub Issues for support requests and bug reports. Do not attach exported JSON files, cookies, credentials, session tokens, or other sensitive browser data to an issue.

Before reporting a problem

  • Confirm the extension is running on a normal http:// or https:// page.
  • Confirm you approved access to the current site when prompted.
  • Describe the browser, operating system, expected behavior, and visible error message.
  • Redact all authentication and private website data from screenshots or logs.
