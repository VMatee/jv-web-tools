# JV-web-tools

Official public website, privacy policy, support documentation, and project information for JV-web-tools.

JV-web-tools is a browser developer utility for exporting cookies and localStorage from the currently active website into structured web-compatible JSON for local development, debugging, testing, migration, and automation workflows.

## Public pages

- Home: https://vmatee.github.io/jv-web-tools/
- Privacy Policy: https://vmatee.github.io/jv-web-tools/privacy/
- Support: https://vmatee.github.io/jv-web-tools/support/

## Privacy model

- Export starts only after explicit user action.
- Site access is limited to the website being worked with.
- Exported data is processed locally.
- JV-web-tools does not operate a backend that receives exported cookies, localStorage data, or generated JSON.
- Exported files can contain reusable authentication information and must be treated as sensitive.

See [SECURITY.md](SECURITY.md) for safe handling guidance.

## Repository purpose

This repository hosts the public-facing pages and documentation used by the JV-web-tools project and Chrome Web Store listing.

## Support

Use [GitHub Issues](https://github.com/VMatee/jv-web-tools/issues) for bug reports and support. Never attach exported browser-state files or credentials to a public issue.
