# Contributing to JV-web-tools

Thanks for helping improve JV-web-tools.

## Before opening an issue

- Search existing issues first.
- State your browser and operating system.
- Provide clear reproduction steps.
- Remove cookies, session values, credentials, and private website data from all examples.

## Scope

JV-web-tools is intentionally focused on exporting current-site browser data for local developer workflows. Changes should preserve that narrow purpose and avoid unnecessary permissions, remote data collection, analytics, or unrelated browser access.
